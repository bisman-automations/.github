# Security policy

This policy covers every bisman-automations repository.

## Supported versions

Only the latest release of each integration gets fixes. Update through HACS
before reporting.

## Reporting a vulnerability

Please report security problems privately, not in a public issue: open the
affected repository's **Security** tab and choose **Report a vulnerability**.
Include what an attacker could do, how to reproduce it, and the integration
and Home Assistant versions. You'll get a reply within a week, and a fix is
released as a patch version with credit in the CHANGELOG if you'd like.

Examples of what counts: a non-admin Home Assistant user reaching an admin-only
setting or action, diagnostics or logs exposing tokens or personal details,
and anything that lets a device or remote service run code in Home Assistant.

## Keeping your reports and issues safe

Never post passwords, API tokens, Matter or HomeKit pairing codes, QR codes,
addresses or account identifiers. Diagnostics files leave out what they can,
but check anything you attach.
