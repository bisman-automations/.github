# Getting help

- **Something's broken:** open an issue in the integration's repository with
  the bug report form, and attach diagnostics if you can.
- **How do I...:** each integration's README covers installation, setup,
  options and troubleshooting. The
  [Home Assistant Community](https://community.home-assistant.io/) is a good
  place for questions about automations and dashboards.
- **A problem with a built-in Home Assistant integration** (Rain Bird, Ford,
  Lutron, Music Assistant and so on): report it to
  [Home Assistant core](https://github.com/home-assistant/core/issues).
- **Security:** see [SECURITY.md](SECURITY.md).
